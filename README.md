# 🎬 Movie Dataset Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a movie dataset to uncover trends, patterns, and insights related to movie popularity, ratings, genres, and audience engagement.

The analysis includes data cleaning, preprocessing, visualization, and statistical exploration to understand the factors influencing movie success.

---

## 🎯 Objectives

* Clean and preprocess movie dataset.
* Analyze movie ratings and popularity.
* Explore genre distribution and trends.
* Identify highly rated and highly voted movies.
* Visualize relationships between different movie attributes.
* Generate actionable insights from the dataset.

---

## 📂 Dataset Information

The dataset contains information about movies, including:

| Feature           | Description                   |
| ----------------- | ----------------------------- |
| Title             | Movie name                    |
| Genre             | Movie genre(s)                |
| Vote_Average      | Average rating given by users |
| Vote_Count        | Number of votes received      |
| Popularity        | Popularity score              |
| Release_Date      | Movie release date            |
| Original_Language | Original movie language       |
| Runtime           | Duration of movie             |

## 🔍 Data Preprocessing

The following preprocessing steps were performed:

### 1. Data Cleaning

* Removed duplicate records
* Handled missing values
* Corrected data types
* Removed unnecessary columns

### 2. Feature Engineering

* Extracted year from release date
* Categorized movies based on ratings
* Processed genre information for analysis

### 3. Data Validation

* Checked for null values
* Verified column consistency
* Examined outliers

## 🔑 Key Insights

* Drama is among the most frequently occurring genres.
* Movie ratings are concentrated within a moderate range.
* Certain genres consistently receive higher audience ratings.
* Vote count and popularity are positively related for many movies.
* Highly rated movies are not always the most popular movies.
